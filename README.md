FoodSystem — Веб-приложение для цифровизации работы университетской столовой
Веб-приложение для автоматизации процессов университетской столовой: оформление и управление заказами, учёт складских остатков, отображение технических карт для поваров и формирование отчётности. Реализовано разграничение прав доступа по ролям: Администратор, Повар, Кладовщик, Клиент.
Исполнитель: Биалиев Эльмар Куантаевич
